How to Import Your .ics Calendar File

GOOGLE CALENDAR

Open Google Calendar, click ⚙ Settings > Import & export > Select the downloaded .ics file and click Import.

APPLE CALENDAR (MAC / IOS)

Double-click the downloaded quest_schedule.ics file. Apple Calendar will open and prompt you to select a calendar to add your classes to.

OUTLOOK

Open Outlook Calendar > Add calendar > Upload from file > Choose the .ics file and select a calendar.
